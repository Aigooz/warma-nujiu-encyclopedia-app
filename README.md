# Warma / 怒九 百科 App

这是一个原生 Android 百科应用，不是网页套壳。应用使用 Android 原生布局重新组织 Warma 百科与怒九百科的数据，提供底部分栏、原生列表、卡片、筛选器、图表和答题界面。

## 主要功能

### 双站点切换

- Warma：包含主号「Warma」与小号「warma养鸽场」。
- 怒九：包含主号「怒九笑」与小号「怒九摸鱼馆」。
- 两个站点的解析结果会保留在内存中，首次启动后切换站点可以立即渲染缓存数据，后台再检查更新。

### 原生页面

- **首页**：UP 档案、核心数据网格、年度弹幕趋势、内容分类、最新视频和弹幕梗。
- **视频**：搜索、账号筛选、多种排序、封面列表和原生视频详情页。
- **详情页**：统计面板、弹幕时段曲线、标签、简介、弹幕峰值和 B 站跳转。
- **榜单**：播放、点赞、弹幕、投币、收藏、评论、分享 Top 10。
- **数据洞察**：年度投稿与累计增长、发布时钟、星期更新节奏、荣誉里程碑、标签关键词云、标签关联 PMI、内容特征聚类、相似内容检索。
- **答题**：分类与难度筛选、10 题挑战、答题反馈和评价。
- **我的**：站点切换、数据刷新、检查 APP 更新、打开网页版。

### 数据同步

APP 启动后会从两个 GitHub Pages 数据源拉取最新 `data.js` 与 `data-quiz.js`，并缓存到本地；首次启动或网络不可用时使用 APK 内置快照兜底。因此百科内容更新时通常不需要重新安装 APP。

## 下载

1. 打开本仓库的 [Releases](https://github.com/Aigooz/warma-nujiu-encyclopedia-app/releases)
2. 下载最新版的 `app-release.apk`
3. 安装到安卓设备

> 首次安装未知来源应用时，系统会提示授权，允许即可。

## 发布新版本

如果 APP 本身升级，只需要：

1. 修改 `app/build.gradle` 中的 `versionCode` 和 `versionName`
2. 提交并打 tag，例如 `v1.1.0`
3. GitHub Actions 会自动构建并发布新的 Release

APP 内提供“检查更新”入口：自动读取 GitHub Release，直接下载 APK，下载完成后唤起系统安装界面，不再需要先跳转浏览器。

## 构建

GitHub Actions 会自动构建。需要本地构建时：

```powershell
gradle assembleRelease
```

当前内置数据快照较大，属于有意设计：它用于保证第一次启动或离线状态下也能浏览完整百科。
